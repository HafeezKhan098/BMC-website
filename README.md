# Berlin Medical Centre — website preview

A responsive, static HTML/CSS/JS website. No framework, npm install, paid plugin or build step is required.

## Run locally
Open `index.html` in a browser.

## Publish
Upload the contents of this folder to a GitHub repository and enable GitHub Pages (Settings → Pages → Deploy from branch → `main` / root). A custom domain can be connected later.

## Before the clinic's final approval / launch
Please have the clinic confirm:
- Exact legal/business name and address formatting.
- Current weekly opening hours (public listings show Saturday–Thursday, 9 AM–9 PM; Friday closed; call to confirm).
- Current list of services and which specialists are available.
- A clinic-approved email address or WhatsApp number if the appointment form should send enquiries directly. The current form prepares an email draft but the recipient is intentionally blank because no verified clinic email was supplied.
- Clinic-owned photographs, logo and any required UAE healthcare licence / regulatory wording.

## Photography
The website uses remotely hosted Unsplash images as illustrative stock photography. They are not photographs of Berlin Medical Centre, its staff or patients. Replace them with clinic-approved photographs when available. Images are loaded from `images.unsplash.com` and require an internet connection.

## Important
This is a marketing website, not a medical advice service. Do not add unverified claims, doctor biographies, testimonials, ratings, insurance promises or treatment guarantees. Confirm all clinic details before connecting a live domain.
